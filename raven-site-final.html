Moderation

.to Timeout a member for a set duration. .to @user 10m spamming
.rto Remove a timeout early. .rto @user
.kick Remove a member from the server. .kick @user reason
.ban Ban a member permanently. .ban @user reason
.warn Send a private warning via DM. .warn @user reason

Roles

.ra Add a role to a member. .ra @user Officers
.rr Remove a role from a member. .rr @user Guests

Voice & Words

.say Post a message through Raven in this channel. .say message
.dm Send a private message to one member. .dm @user message
.dmall admin only Send a private message to every member. .dmall message
.join / .leave Join or leave the voice channel you're currently in.

Utility

.raven Show the full command list from within Discord.
